# İŞLETME TAKİP APK v1.2

İŞLETME TAKİP-MK26.xlsx'in mevcut yapısına göre ilk APK ekran iskeleti.

Görünür Excel sayfaları: 36. Gizli sayfalar veri amaçlı tutulacak ve mobil menüde gösterilmeyecek.

İçerik:
- Logo + giriş ekranı
- Giriş ekranında sol üst logo
- Ana Menü
- Excel'deki görünür ekran adları
- Her ekranda sol üst logo
- Logo -> Ana Menü

Bu sürüm gerçek Excel hücrelerini henüz APK içine gömmemektedir. Sonraki aşama gerçek veri okuma ve merkezi senkronizasyondur.
